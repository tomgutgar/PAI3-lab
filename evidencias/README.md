# Evidencias

Logs y capturas de cada parte, antes y después. Es obligatorio entregar logs de TODAS las herramientas.

Convención de nombres: `<herramienta>-<equipo>-<antes|despues>-<fecha>.<ext>`

```
sistemas/   lynis.log + report.dat (antes/después de cada equipo)
navegador/  capturas about:policies, badssl, coveryourtracks
movil/      volcados adb, pcap de PCAPdroid, informes de escaneo
web/        informe HTML de ZAP, session, peticiones exportadas
```
